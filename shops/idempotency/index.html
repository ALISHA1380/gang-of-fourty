عملیاتی idempotent (خودتوان) است که یک بار یا ده بار انجام دادنش نتیجه یکسان دارد. اگر مشتری دو بار روی «پرداخت» بزند، نباید دو بار پول کم شود. در HTTP متدهای GET، PUT و DELETE خودتوان‌اند ولی POST نیست.
